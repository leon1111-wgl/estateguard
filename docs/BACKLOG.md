# 后续迭代：从可运行基线到社区专项系统

优先级根据用户任务和证据调整；不是承诺已实现。已完成 CNRPark 真实训练与跨视角基线，已冻结用户认可的页面版面。

已修复慢加载模拟班次静默清空等待期间新复核的问题：只在替换数据准备好后确认，取消保留记录与附件；应用规则、导入或模型候选送审后，旧读取与旧错误不会再覆盖当前工作区。仍是本标签页内存与手动导出交接，没有后台自动保存、跨标签页协调或多人记录合并。

已修复视频中车辆先驶入再停稳却不产生候选的问题：仅达标的稳定片段进入复核，分段标识阻止送审后重新拼接两次停留；驶离、区域重入、丢检、慢移与交接恢复已有回归。真实模型验证使用 CC0 图片合成动画，不作为社区停车评测；下一步仍需有许可的真实多目标短片与人工轨迹真值，评估遮挡、身份切换和相机抖动。

已修复未使用的停留或方向参数阻断其他分析规则的问题：控件按用途启用，闲置草稿保留但不参与校验或报告；切回停车/方向规则重新校验，沿用现场不会用空参数清除其他草稿。当前仍只提供本标签页现场复用，具名预设和跨会话配置恢复尚未实现。

已修复事件复核附件替换失败会销毁原画面的问题：解码成功才替换，坏图/坏视频保留证据与草稿，连续选择和工作区恢复相互隔离。只验证可读取；完整视频损坏检测、跨会话媒体绑定与可信证据归档尚未实现。后续若扩展交接附件，应先明确授权、保留期限和可复现关联方式。

已修复停车交班恢复后回到默认相机、首个快照和默认模型的问题：文件保留交接位置与人工筛选，恢复后停止回放；模型相关筛选提示重跑，坏文件原子拒绝，旧格式明确回退。仍是手动文件交接，没有共享账户、跨班次同步、可信签名或多人冲突合并。

已修复车位人工复核被模型分数错误筛选的问题：已确认退出待办、无法判断保留为需补证据，支持当前快照连续复核和导出恢复。后续模型改进须保留这套人工完成规则，不能靠高低分自动结案。

已解决首次模型加载没有真实进度、无法取消的问题，并支持校验后的公共资源缓存、损坏重下和失败重试。取消/弱网/禁用缓存/存储挂起已有回归；网络下载和初始化分别测量，缓存不承诺消除推理引擎初始化耗时。

已修正分数下限同时改变 NMS 重叠阈值的问题。公开校车图提高分数后出现同车双框、双候选的错例保留；分数和重叠阈值现在分开，检测报告记录实际后处理与采样设置。没有把此工程修正记为模型训练或总体精度提升。

已修复换素材静默继承来源、时间、片段起点和 ROI 的问题。新素材先清空这些设置；可显式沿用上次已核对的现场，但不继承时间/起点，原始尺寸变化时不继承 ROI。规则分析要求逐素材核对；未知时间仍可运行通用物体检测。失败替换保留上一份素材和报告，ROI 摘要随实际范围更新。具名预设、跨会话配置导出恢复仍未实现，后续应复用这一确认边界。

已完成冻结 MLP32 的全部 6,413 张输入重算、错例分布审查及错误类型/车位筛选。原不确定区间仅覆盖 127 / 1,485 张错误；B:12、B:40、B:30 贡献 271 / 1,134 张错误空闲。错例可导出来源清单、回到原图重新推理和复核；原图失败现在阻止明确确认，并提供重试与需补证据记录。没有更改模型或声称精度提升。

已完成冻结编码器迁移（DINOv2-small 默认、MobileNetV2 迁移头）与 CNR-EXT 144,965 张保留测试：EXT 平衡正确率 95.88% / 94.32%，MLP32 88.48%。训练视角与逐样本现场校准的分流阈值在新视角超标；改为车位·日计数、跨天检验后，5% 目标下仍有摄像头在冬季超标。

已加入自动判定的随机抽检与自动撤销（协议附录 5，回放前写定）：约 10% 车位·日按哈希抽中改送人工，按车位·日累积出错，单侧似然比序贯检验达到证据值 40 即撤销该侧阈值。EXT 按日期回放（DINOv2、5% 目标）误撤销 0 / 8，但 3 个超标空闲侧阈值只撤销了 C7 一个，且在错误集中出现约 3 天后；实际生效的自动判空闲车位·日出错 7.25% → 6.60%，仍超标，人工占比 24.8% → 34.4%。

**2026-10-19 检测器**：D-FINE-N 已成为默认（COCO 测试半 AP 42.0 对 25.4），但大件类别在 0.6 下精确率下降明显（餐桌 61%、床 68%）。下一步需在授权的客梯/小区画面上按类别设定分数下限，测每小时误报与事件召回；低端设备的单线程耗时与回退策略也待测。

**2026-10-18 后的首要问题**：漂移是突发、跨相机的（EXT 错误集中在 2016-01-12 至 01-15 与 02-12，多相机同时变差），而累积式检验会被之前多日的正确抽检拖慢。下一步在**新的数据**上预先登记更快的规则（重置或滑动窗口的 CUSUM、按日期或跨摄像头汇总告警），并回放撤销后的重新校准；不能用 EXT 回放挑选。页面抽检已改为保存前隐藏模型概率，真实抽检员的判断质量仍未验证。其次：其他停车场与夜间数据的独立测试、编码器微调或蒸馏与当前冻结方案的同协议比较。

**2026-10-16 时的数据驱动优先项（已部分完成）**：MLP32 的 B 视角仍有 1,134 张错误空闲，其中 1,037 张分数低于等于0.35。下一步核验新数据/编码器的许可与小规模预算，锁定新的独立相机或场地测试，比较更强轻量编码器、迁移学习与校准。B 已参与公开错例分析，据此开发时须改标开发基准。报告平衡正确率、占用漏判、复核覆盖率与残余错误，同时保留旧基线。尚无证据认定低分错误由某一种光照或遮挡因素造成，需可复查的人工标注；不要反复用公开测试选模型后声称盲测。
