# 模型卡 · SSDLite MobileNet V2

## 当前实际实现

- 模型：TensorFlow.js COCO-SSD，base=`lite_mobilenet_v2`；通用 COCO 预训练，支持官方 80 个物体类别。
- 运行库：TensorFlow.js 4.22.0；检测包 2.2.3。
- 权重：18,034,528 字节（约 17.20 MiB），另有模型结构与运行库。全部从本站加载；来源与 SHA-256 见 `web/assets.lock.json`。
- 输入：本地 JPEG/PNG/WebP 或浏览器可解码 MP4/WebM；单文件最多 100 MB；推理前画面宽度限制为 960px；视频每秒一帧，最多 20 帧。
- 输出：物体类别、像素框归一化坐标、检测分数。分数不是经过本项目校准的概率。
- 后端：优先 WebGL，初始化失败尝试 CPU。设备兼容性需要持续验证；当前实测后端为 WebGL。
- 下游：同类框的贪心 IoU 关联（阈值 >0.2，最大采样间隔 1.6s），用户指定区域与停留/方向规则。不同帧物体身份关联可能出错；不是身份识别系统。

## 明确没有完成的工作

未针对客梯/小区数据做指令微调、领域检测微调、蒸馏或量化。未部署大语言模型，未运行视频语言模型。没有生产监控接入、真实住户行为测试或事故减少测量。

通用模型没有“电梯损坏”“违规停车”“乱扔垃圾”等行为标签。家具/行李箱只覆盖部分大件，普通纸箱、搬运柜体和垃圾袋可能完全漏检。遮挡、夜间、小目标、摄像头移动和多人交叉都可能破坏检测或关联。

## 适用方式

作为可复查的边缘推理基线和人工复核辅助。现场人员定义区域与语义，模型提供线索，人工查看原视频并记录判断。不要把没有候选理解为安全，也不要根据检测框自动归责。

## 升级模型的门槛

先建立合法的社区场景测试集与视频级隔离划分。使用同一基准比较模型、阈值、跟踪器和量化版本，报告每小时误报、事件召回、漏检分布与端到端 P50/P95 延迟，同时保留旧基线。只有测量支持才改默认模型。
