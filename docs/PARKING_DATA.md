# 车位巡检：公开数据、实际训练与测试

这条链路回答一个具体问题：值班员面对整排车位，如何按历史时间检查占用、找到模型错判并保留复核记录？它采用公开停车场的真实裁剪图片，独立训练小型占用分类器，并在浏览器运行。原有通用检测、事件规则与交接功能保留。

## 数据与许可

来源为 Amato、Carrara、Falchi、Gennaro、Vairo 发布的 [CNRPark](http://cnrpark.it/) 基础子集，下载自作者 [deep-parking 官方归档](https://github.com/fabiocarrara/deep-parking/releases/download/archive/CNRPark-Patches-150x150.zip)。数据按 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) 使用和分发，原作者署名与变更范围见 [数据声明](../web/data/parking/NOTICE.md)。这不是原雇主或住户视频，也不是完整 CNRPark-EXT。

归档 36,596,809 字节，SHA-256 `2dc9b13892595e599e1f5025ddcce08ef7287babbb978670580c60abd86c5fdb`。脚本核验大小、哈希、ZIP CRC、12,584 个唯一样本标识及两类标签。

实际解包有摄像头 A 的 6,171 张图片（2015-07-03）和 B 的 6,413 张（2015-07-08）。每张是 150×150 单车位裁剪，标签为 free/busy。用同一摄像头、日期和时刻重组历史快照；不是连续视频，也没有完整场景坐标。车位编号只在该摄像头内有意义。保留数据源钟面时间，源数据未声明时区，不转成北京时间。

## 先划分，再训练和选模

按原始帧分组，绝不把同一帧的车位随机散进训练与测试。摄像头 B 预先整体留作测试；A 的前 70% 帧训练，后 20% 验证，中间 10% 不使用。划分由相机、日期、时间决定，与标签无关。

| 分区 | 图片 | 原始帧 | 相机与日期 | 钟面时间 |
| --- | ---: | ---: | --- | --- |
| 训练 | 4,284 | 84 | A，2015-07-03 | 08:05–15:00 |
| 排除间隔 | 612 | 12 | A，2015-07-03 | 15:05–16:00 |
| 验证 | 1,275 | 25 | A，2015-07-03 | 16:05–18:05 |
| 测试 | 6,413 | 121 | B，2015-07-08 | 08:05–18:05 |

额外检查原始 JPEG 哈希和解码 RGB 哈希；当前没有跨分区完全重复图片需要排除。完整 [split CSV](validation/parking-split.csv) 包含来源路径、标签、两种哈希、最终分区。训练和验证仍是同一视角；测试是同一停车场的不同视角和日期，可能存在相同车辆。它不能证明跨小区泛化，也不能证明不同季节与天气的表现。

## 真实训练了什么

- 预处理：将 RGB 原图按目标像素中心最近邻采样为 32×32；分成 4×4 个空间单元，每单元计算 RGB 均值、标准差与 9 桶梯度方向直方图，共 240 维。不是使用文件名或标签生成预测。
- 固定候选：逻辑回归、240→32 tanh→1 sigmoid 的全连接神经网络；二者从随机初始化开始，各 40 轮。它是可检查的经典轻量基线，没有冒充前沿视觉模型或复现作者 CNN。
- 训练集拟合特征均值、标准差（下限 0.05）；Adam，学习率 0.003，L2 系数 0.0001，批量至多 128，种子 20261015。
- 只按验证集交叉熵选结构与检查点：线性 0.041702；MLP32 0.025402，第 39 轮。然后冻结模型，评估 B。测试标签未参与优化、选模或阈值调整。
- 最终 7,745 个可训练参数；权重 JSON 约 169 KiB。模型哈希 `f82d56b0c1ed3935c351a5b479961dde19d786d8151f775abe4325d41685192b`。浏览器直接用像素特征与这些权重计算，不读取离线分数作为在线预测。
- Python 3.12.14、NumPy 2.3.5、Pillow 12.3.0。此次 CPU 脚本用时 12.225 秒，包含特征准备与文件写出；不是部署延迟指标。完整 [两候选逐轮日志](validation/parking-training-log.json) 与 [模型文件](../web/models/parking-occupancy/model.json) 可查。

原来的 COCO-SSD / SSDLite MobileNet V2 继续使用公开预训练权重，**本轮没有微调它**。这次完成的是独立的车位占用模型训练，不是指令微调、蒸馏、量化或违规行为训练。

## 完整测试结果

| 指标 | MLP32 | 训练集多数类基线：全部预测占用 |
| --- | ---: | ---: |
| 测试图片 | 6,413 | 6,413 |
| 正确率 | 76.84% | 74.55% |
| 平衡正确率 | 77.39% | 50.00% |
| 占用召回率 | 76.28% | 100.00% |
| 实际占用却报空闲 | 1,134 | 0 |
| 实际空闲却报占用 | 351 | 1,632 |

混淆矩阵行是真实空闲/占用，列是预测空闲/占用：`[[1281,351],[1134,3647]]`。基线看似正确率不低，是因为测试集约 74.6% 的车位被占用；平衡正确率同时看两类，说明模型学到了有用区别，但对占用车辆的漏判仍严重。不能据此直接提供可靠空位引导。

评测分类阈值固定为 0.5。界面另把 0.35–0.65 作为优先复核带，落入其中 263 张；它没有排除这些样本来提高指标。更关键的是，低于等于 0.35 的“空闲”结果仍有 1,037 张实际上被占用，所以低分并不代表安全或可靠，分数不是校准过的概率。

[完整评测](../web/data/parking/evaluation.json)、[全部逐样本预测](../web/data/parking/test-predictions.json)、[全部测试图片与快照索引](../web/data/parking/manifest.json) 都随站点发布。1,485 个错例全部保留，可在「评测与模型」中选取并回到原图重新推理。结果不是人工挑选成功图片得到的展示指标。

## 可使用的工作流

1. 打开「车位巡检」，按历史时刻查看真实车位图，点击「分析当前快照」。初始未分析项不计为空闲。
2. 自动回放逐快照运行模型，显示数据源真实采样间隔；播放速度不解释为停车持续时间。
3. 筛选待复核或与标签不一致的车位。原始标注默认隐藏，只用于对照；人工结论、模型预测、数据标签分别保存。
4. 写下遮挡、阴影等判断依据，导出 JSON；之后恢复人工结论。恢复文件中的旧预测不会冒充本次推理。
5. 上传自己的单车位裁剪图做本地测试。新相机没有校准或领域验证，完整停车场图也不会自动切出每个车位。

人工复核记录上限24 MiB，完整导出/恢复文件上限32 MiB；为后续新增预测预留空间，超限操作会保留已有记录并明确提示。复核状态保存在当前标签页内存，关闭前须导出。

图片读失败仍是未分析，可重试；推理可停止。正常占用不会进入原有违停事件队列。没有后端、实时监控接入、身份识别或自动处罚。

## 从零复现

Python 3.12 与 Node.js 22+。下载只用于公开训练数据，不需要账户或付费计算。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-training.txt
mkdir -p artifacts/datasets
curl -L --fail --retry 3 -o artifacts/datasets/CNRPark.zip \
  https://github.com/fabiocarrara/deep-parking/releases/download/archive/CNRPark-Patches-150x150.zip
OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  python scripts/train_parking.py --archive artifacts/datasets/CNRPark.zip
python -m unittest discover -s tests/training -p 'test_*.py'
node --test tests/parking.test.mjs
python scripts/verify_parking.py
```

脚本产生权重、全量测试预测、图片、划分清单、日志和 Python/JavaScript 数值对照样例；耗时随机器变化，其他平台浮点实现也可能有微小差别。发布新权重前需更新 `web/assets.lock.json` 对应条目并通过 `scripts/verify_assets.py`，不可覆盖哈希掩盖来源变化。原始训练图片不打包到网页，可由同一官方归档和 split CSV 重建。

## 下一轮如何改进

先统计错例与遮挡、尺度、光照的关联，标明是人工观察还是验证结论。比较更好的轻量图像编码器或已有停车模型时，保留本轮基线与划分；B 结果已经公开，后续若参考它调参，必须标成开发集，并增加新的独立相机/场地测试，不能继续叫完全未见测试集。其次校准分数与复核策略，报告覆盖率以及明确分类里的残余错误；不能只以提高准确率或缩小复核量为目标。

参考 [CNRPark 原论文](https://doi.org/10.1109/ISCC.2016.7543901) 和 [Revising deep learning methods in parking lot occupancy detection](https://arxiv.org/abs/2306.04288) 的泛化评估问题；后者本轮查阅摘要，未复现论文模型或采用其结论作为本项目性能。
